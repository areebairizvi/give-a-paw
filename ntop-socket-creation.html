nTop Socket Creation¶

Our custom nTop workflow turns a cleaned 3D scan into a printable lattice socket. This page documents each block in the workflow: what it does, the inputs you can change, and an interactive demo of how each input reshapes the final socket.

Latticing¶

The Socket Lattice block converts the solid socket shell into a flexible lattice that can bend with the animal's residual limb while staying strong enough to carry load. Below is the block as it appears in nTop.

Tip: Click any input on the block to expand its live demo. Each demo changes one input while the others stay at their defaults, so the difference you see comes from that parameter alone. Drag the model to rotate it, scroll to zoom, and use the view cube to snap or step the orientation.
